Accumulator: Operates directly on the accumulator

Immediate: Specify an 8-bit constant within the instruction (ie give it an "immediate" value to use)

Absolute: Instruction specifies the exact 16-bit memory address to perform the operation

Absolute X: Takes in a 16-bit address from the instruction and also adds content of x register
    ex: LDA $2000,X
    Adress = $2000 + X

Absolute Y: Same as Absolute X except uses the Y register

Zero Page: The same as absolute except given an 8-bit constant it operates solely on the first 256 bytes of memory (the zero page)

Zero Page X: Takes an 8-bit address and adds in contests of X register. Take modulo of 256 to make sure it remains in the zero page

Zero Page Y: Same as Zero Page X but with the Y register


Indirect: The instruction contains a 16-bit address which identifies the location of the least significant byte of another 16 bit memory address which is the real target of the instruction.
    - NOTE: Only JMP uses this

Indirect X: Indexed indirect addressing is normally used in conjunction with a table of address held on zero page. The address of the table is taken from the instruction and the X register added to it (with zero page wrap around) to give the location of the least significant byte of the target address.
